# 基本的な流れ

AdvanceRailway では、次の 4 ステップで鉄道ネットワークを登録します。

1. **駅を 2 つ作る** — 路線の始点と終点になります。
2. **2 駅を結ぶ路線を作る** — `ar inspect` で線路を自動探索して登録します。
3. **路線をグループにまとめる**（任意） — 「〇〇線」という路線名と色を付けられます。
4. **経路検索を使う** — 登録した路線をもとに 2 駅間の最短経路を調べられます。

## 1. 駅を作る

駅にしたい場所に立って、次のコマンドを実行します。

```
ar station add <stationId> <name>
```

- `stationId` : 駅の ID（英数字・`_`・`-`）
- `name` : 駅の表示名

例えば `ar station add mr01 もりもと` とすると、現在地に「もりもと」駅が作られます。
これを路線の両端で行い、駅を 2 つ用意してください。

座標指定や名前・色の変更など、詳しくは [駅コマンド](/docs/commands/station) を参照してください。

## 2. 路線を作る

路線の登録方法はいくつかありますが（[路線コマンド](/docs/commands/railway) 参照）、
最も簡単なのは `ar inspect` を使う方法です。座標や分岐フラグを手で調べる必要はありません。

1. `ar inspect` を実行し、路線の始点付近のレールをクリックします。
2. そのレールから線路網が自動で探索され、たどり着ける**終端の一覧**がチャットに表示されます。
3. 目的の終端の行にある `[作成]` をクリックすると、座標とフラグが入った
   `ar railway add` コマンドがチャット欄に自動入力されるので、そのまま実行します。

これで 2 駅を結ぶ路線が登録されます。距離（所要時間）はレールの長さから自動計算されます。

### 探索を途中の駅で止めたい場合

線路が 1 本につながったまま駅が 3 つ以上並んでいると、探索は線路の端まで進んでしまいます。

```mermaid
graph LR
    A[駅A] --> B[駅B]
    B --> C[駅C]
```

上の図で駅 A から `ar inspect` を実行すると、探索は駅 B を素通りして駅 C まで到達し、
「駅 A 〜 駅 C」の路線が作られてしまいます。

そこで使うのが**停止ブロック**です。デフォルトでは**金ブロック**が停止ブロックに設定されており、
レールの直下に置くと `ar inspect` の探索はそこで終了します。

  <figcaption className="text-center text-sm">駅Bの様子</figcaption>
</figure>

駅 B のレールの下に金ブロックを置いてから駅 A で `ar inspect` を実行すれば、
「駅 A 〜 駅 B」の路線が作られます。同様に駅 B 側から探索すれば「駅 B 〜 駅 C」も登録できます。

停止ブロックの種類は設定で変更できます。詳しくは
[`ar inspect` — 線路の解析](/docs/commands/general#ar-inspect--線路の解析) を参照してください。

## 3. 路線をグループにまとめる

グループは「〇〇線」という路線名を表し、squaremap 上での表示色を持ちます。
複数の路線（railway）を 1 つのグループに入れると、マップ上で同じ色のひとつながりの路線として表示されます。

```
ar group add <groupId> <name>
ar railway set group <railwayId> <groupId>
ar group set color <groupId> <r> <g> <b>
```

例:

- `ar group add mr もりもと線` — 「もりもと線」グループを作成します。
- `ar railway set group mr01_mr02 mr` — 路線をもりもと線に追加します。
- `ar group set color mr 46 139 87` — もりもと線の色を変更します（RGB 各 0〜255）。

詳しくは [グループコマンド](/docs/commands/group) を参照してください。

## 4. 経路検索

路線を登録すると、誰でも経路検索が使えるようになります。

```
ar railway route <from> <to>
```

`ar railway route <to>` のように目的地だけ指定すると、現在地から検索します。

:::note
駅は **表示名** でも指定できます（タブ補完に名前が候補として出ます）。
`ar railway route もりもと 赤松` のように名前で検索できます。
:::

レールでつながっていない駅どうしでも、同一ワールド内なら徒歩区間で補完して経路を表示します。

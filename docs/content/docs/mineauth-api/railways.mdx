# 路線 API

## レスポンス形式（Railway）

```json
{
  "id": "central-to-north",
  "group": "main-line",
  "world": "world",
  "lineType": "UP_LINE",
  "fromStation": "central",
  "toStation": "north",
  "timeRequired": 30,
  "startPoint": { "x": 0.0, "y": 64.0, "z": 0.0 },
  "endPoint": { "x": 100.0, "y": 64.0, "z": 0.0 },
  "directionPoint": { "x": 50.0, "y": 64.0, "z": 0.0 }
}
```

- `group` は所属グループが無ければ `null`。
- `timeRequired` は所要時間（秒）。

## 一覧・単体取得

- `GET /railways` — 全路線を一覧取得します（[ページング](/docs/mineauth-api#ページング)対応）。
- `GET /railways/{id}` — 路線を 1 件取得します。存在しなければ `404`。

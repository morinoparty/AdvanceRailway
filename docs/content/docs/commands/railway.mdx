# 路線コマンド

閲覧: `advancerailway.railway.view`（全員） / 経路: `advancerailway.railway.route`（全員） / 編集: `advancerailway.railway.manage`（OP）

## 閲覧

- `ar railway list [page]` — 路線の一覧をページ表示します。
- `ar railway info <railwayId>` — 路線の情報を表示します。

## 経路検索

- `ar railway route <from> <to>` — 2 駅間の最短経路（レール＋徒歩、A\* 探索）を表示します。
- `ar railway route <to>` — 現在地から目的駅までの最短経路を表示します（プレイヤー専用）。

## 追加・引き直し

- `ar railway add <railwayId> <start> <end> <flags>` — 路線を追加します。既存の路線 ID を指定すると経路を引き直して上書きします（グループ・種別の設定は維持。旧 `ar railway redraw` は統合されました）。

引数:

- `start` / `end` : 始点・終点のレール座標。それぞれ最も近い駅が自動的に選ばれます。
- `flags` : **経路フラグ**（必須）。`N` / `S` / `E` / `W` の並びで、**1 文字目が始点からの出発方角**、2 文字目以降が分岐点（ポイント）で選ぶ方角です（例: `EE` = 東へ出発し、最初の分岐で東へ）。

所要時間はレールの長さから自動計算されます。

### 経路フラグ

経路の途中に分岐（ポイント）がある場合、対応するフラグがないとトレースは失敗します。
[`ar inspect`](/docs/commands/general#ar-inspect--線路の解析) が表示する `[作成]` をクリックするか、
下の `explore` が表示する `[作成]` をクリックすると、探索で確定したフラグ付きのコマンドが
自動入力されるので、通常は手で書く必要はありません。

## 経路候補の調査

- `ar railway explore point <start> <end>` — 2 点間を結ぶ経路の候補を、全方向・全分岐について列挙します（フラグ長の制限なし）。各候補には `add` 用の `[作成]` が付きます。
- `ar railway explore railway <railwayId>` — 登録済み路線の始点・終点間で同じ調査を行います。現在保存されている経路には `(現在)` が付き、他の候補は `[作成]` で引き直せます。

## その他の編集

- `ar railway remove <railwayId>` — 路線を削除します。
- `ar railway set line-type <railwayId> <lineType>` — 路線の種別を変更します。
- `ar railway set group <railwayId> <group>` — 路線をグループに追加します（`none` を渡すと解除。旧 `ar railway unset group`）。
- `ar railway set from-station <railwayId> <stationId>` — 始点駅を変更します。
- `ar railway set to-station <railwayId> <stationId>` — 終点駅を変更します。

## データ形式の移行（V1/V2 → V3）

路線データには 3 つの形式があります。

- **V1（旧形式）** — 分岐情報を持ちません。
- **V2（旧形式）** — 分岐フラグを保持しますが、出発方向は隣接レール座標（directionPoint）で表します。
- **V3（現行形式）** — `version` フィールドを持ち、出発方角を組み込んだ `flags` 文字列（例: `"EE"`）だけで経路を再現・検証できます。`add` で作られる路線は常に V3 です。

<br />

- `ar railway migrate` — 旧形式 (V1/V2) の路線データを V3 に一括移行します。
  V2 は再トレースなしで変換されます。V1 は再トレースが必要で、分岐があって再トレースできない
  路線は報告されるので、`add` で `flags` を指定して引き直してください。

:::note
V3 の路線は `ar railway check` で開始点＋flags から再トレースして検証できます。
レールが撤去・変更されて保存時の経路と一致しなくなっている場合は報告されます。
:::

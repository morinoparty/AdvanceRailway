# 路線コマンド

閲覧: `advancerailway.railway.view`（全員） / 経路: `advancerailway.railway.route`（全員） / 編集: `advancerailway.railway.manage`（OP）

## 閲覧

- `ar railway list [page]` — 路線の一覧をページ表示します。
- `ar railway info <railwayId>` — 路線の情報を表示します。

## 経路検索

- `ar railway route <from> <to>` — 2 駅間の最短経路（レール＋徒歩、A\* 探索）を表示します。
- `ar railway route <to>` — 現在地から目的駅までの最短経路を表示します（プレイヤー専用）。

## 追加・引き直し

- `ar railway add <railwayId> <start> <direction> <end> [flags]` — 路線を追加します。
- `ar railway redraw <railwayId> <start> <direction> <end> [flags]` — 路線の経路を引き直します（旧 `ar railway update`）。

引数:

- `start` / `end` : 始点・終点のレール座標。それぞれ最も近い駅が自動的に選ばれます。
- `direction` : 始点から進み始める隣のレール座標（トレースの初期方向）。
- `flags` : **分岐フラグ**（任意）。分岐点で選ぶ方角を `N` / `S` / `E` / `W` の並びで先頭から順に指定します（例: `EE`）。

所要時間はレールの長さから自動計算されます。

### 分岐フラグ

経路の途中に分岐（ポイント）がある場合、`flags` を指定しないとトレースは失敗します。
[`ar inspect`](/docs/commands/general#ar-inspect--線路の解析) が表示する `[作成]` をクリックすると、
探索で確定したフラグ付きのコマンドが自動入力されるので、通常は手で書く必要はありません。

## その他の編集

- `ar railway remove <railwayId>` — 路線を削除します。
- `ar railway set line-type <railwayId> <lineType>` — 路線の種別を変更します。
- `ar railway set group <railwayId> <group>` — 路線をグループに追加します（`none` を渡すと解除。旧 `ar railway unset group`）。
- `ar railway set from-station <railwayId> <stationId>` — 始点駅を変更します。
- `ar railway set to-station <railwayId> <stationId>` — 終点駅を変更します。

## データ形式の移行（V1 → V2）

路線データには 2 つの形式があります。

- **V1（旧形式）** — 分岐情報を持ちません。
- **V2（現行形式）** — 分岐フラグを保持し、開始点＋フラグから経路を再現・検証できます。`add` / `redraw` で作られる路線は常に V2 です。

<br />

- `ar railway migrate` — 旧形式 (V1) の路線データを再トレースして V2 に一括移行します。
  分岐があって再トレースできない路線は報告されるので、`redraw` で `flags` を指定して引き直してください。

:::note
V2 の路線は**サーバー起動時**に開始点＋分岐フラグから自動で再トレースされ、
レールが撤去・変更されて保存時の経路と一致しなくなっている場合はコンソールに警告が出ます。
:::

# 一般コマンド

- `ar info` — プラグインの情報（バージョン・作者・サイト）を表示します。（全員）
- `ar help` — コマンドの一覧を表示します。（全員）
- `ar reload` — マップと設定を再読み込みします。（OP）
- `ar debug block [distance]` — 見ているブロックの座標を表示します（旧 `ar targetBlock`・デバッグ用）。（OP）

## ar inspect — 線路の解析

`ar inspect` を実行してからレールをクリックすると、そのレールから線路網を探索して**すべての終端**を列挙します（プレイヤー専用・OP）。

### 分岐の全探索と方角フラグ

分岐（ポイント）があっても探索は止まりません。すべての経路を探索し、各終端には
**分岐点で選んだ方角の並び**がフラグとして表示されます。

- 方角は `N`（北）/ `S`（南）/ `E`（東）/ `W`（西）。
- 例: `[分岐: EE]` = 分岐を 2 回通過し、どちらも東へ進んだ経路の終端。
- 分岐のない経路にはフラグが付きません。
- ポイント（分岐レール）は、レバー等での**切替状態に関係なく**、物理的に接続しうる全ての脚を分岐として検出します。隣り合っているだけで互いに接続していない並行線は分岐扱いになりません。

各終端の行にある `[作成]` をクリックすると、`ar railway add` コマンドが**フラグ付きで**チャット欄に入力されます。
そのまま実行すれば分岐を含む路線も登録できます（詳細は [路線コマンド](/docs/commands/railway) を参照）。

### 終端の種類

| 表示 | 意味 |
| --- | --- |
| （表示なし） | レールの末端（先にレールがない） |
| `[停止ブロック]` | レール直下が設定された停止ブロックだった |
| `[環状/合流]` | 既に通過したレールに戻ってきた（環状線路・合流） |

### 停止ブロック

レールの**直下**（y−1）のブロックが設定リストに含まれる場合、探索はその地点で打ち切られ、終端として扱われます。
長大な路線の途中に意図的な「区切り」を作りたいときに、レールの下に金ブロックを置いてください。

`config.json` で変更できます:

```json
{
  "inspectStopBlocks": ["GOLD_BLOCK"],
  "inspectMaxEndpoints": 16
}
```

- `inspectStopBlocks` — 探索を打ち切るブロックの [Material 名](https://jd.papermc.io/paper/1.21/org/bukkit/Material.html) のリスト。既定は金ブロックのみ。不正な名前は起動時に警告されスキップされます。
- `inspectMaxEndpoints` — 1 回の探索で列挙する終端数の上限（既定 16）。
- 探索の総ステップ数は既存の `limit` 設定が上限になります。

:::note
クリックしたレール自身の直下は判定されません。停止ブロックの上に立って、その両側をそれぞれ探索できます。
:::

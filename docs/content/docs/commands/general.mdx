# 一般コマンド

- `ar info` — プラグインの情報（バージョン・作者・サイト）を表示します。（全員）
- `ar help` — コマンドの一覧を表示します。（全員）
- `ar reload` — マップと設定を再読み込みします。（OP）
- `ar debug block [distance]` — 見ているブロックの座標を表示します（旧 `ar targetBlock`・デバッグ用）。（OP）

## ar inspect — 線路の解析

```
ar inspect [flags] [--to <駅>]
```

`ar inspect` を実行してからレールをクリックすると、そのレールから線路網を探索して**すべての終端**を列挙します（プレイヤー専用・OP）。

分岐の多い場所では終端が一気に増えて読みづらくなるため、見たい経路をあらかじめ絞り込めます。

### 絞り込み

- **`flags`** — たどる方角の並び（例 `E` / `EE`）。**1 文字目が出発方角**で、以降が分岐点で選ぶ方角です。
  指定した並びから外れる分岐はそもそも探索しないため、結果が減るだけでなく探索も軽くなります。
  指定を使い切ったあとの分岐は絞り込まれず、全パターンが列挙されます。
- **`--to <駅>`**（短縮: `-t`） — その駅を終点とする経路だけを表示します。駅は表示名・slug・UUID のいずれでも指定できます。

どちらも省略できます。除外された件数はチャットに表示されるので、結果が 0 件になった場合も理由が分かります。

```
ar inspect E              # 東へ出発する経路だけ
ar inspect EE             # 東へ出発し、最初の分岐でも東へ進む経路だけ
ar inspect --to 赤松       # 赤松駅を終点とする経路だけ
ar inspect E --to 赤松     # 東へ出発して赤松駅に着く経路だけ
```

### 分岐の全探索と方角フラグ

分岐（ポイント）があっても探索は止まりません。クリック地点から**全方向・すべての経路**を探索し、
各終端には**出発方角＋分岐点で選んだ方角の並び**がフラグとして表示されます。

- 方角は `N`（北）/ `S`（南）/ `E`（東）/ `W`（西）。
- 例: `[flags: EE]` = 東へ出発し、分岐で東へ進んだ経路の終端。1 文字目は常に出発方角です。
- 複線・待避線のように分岐後に合流する線路も、それぞれの経路が別のフラグで列挙されます。
- ポイント（分岐レール）は、レバー等での**切替状態に関係なく**、物理的に接続しうる全ての脚を分岐として検出します。隣り合っているだけで互いに接続していない並行線は分岐扱いになりません。
- 始点と同じ駅に戻ってくる経路は表示されません。

各終端の行にある `[作成]` をクリックすると、`ar railway add` コマンドが**フラグ付きで**チャット欄に入力されます。
そのまま実行すれば分岐を含む路線も登録できます（詳細は [路線コマンド](/docs/commands/railway) を参照）。

### 終端の種類

| 表示 | 意味 |
| --- | --- |
| （表示なし） | レールの末端（先にレールがない） |
| `[停止ブロック]` | レール直下が設定された停止ブロックだった |

### 同じ線路を 2 度通らない

探索は **1 本の経路が同じレールを 2 度通らない**ように進みます。既に通ったレール（クリックした
レールを含む）に戻ってきた経路は、その場で打ち切られ、**一覧には出しません**。始点と終点が
同じ線路上に乗ってしまい、路線として登録できないためです。

除外した件数は「（同じ線路に戻ってくる経路 N 件は除外しました）」として表示されるので、
終端が 0 件になった場合もその理由が分かります。

判定は経路ごとに独立しています。複線・待避線のように**分岐したあと合流する**線路では、
本線経由と待避線経由の両方が別々のフラグで列挙されます（合流したからといって片方が
消えることはありません）。

### 停止ブロック

レールの**直下**（y−1）のブロックが設定リストに含まれる場合、探索はその地点で打ち切られ、終端として扱われます。
長大な路線の途中に意図的な「区切り」を作りたいときに、レールの下に金ブロックを置いてください。

`config.json` で変更できます:

```json
{
  "inspectStopBlocks": ["GOLD_BLOCK"],
  "inspectMaxEndpoints": 16
}
```

- `inspectStopBlocks` — 探索を打ち切るブロックの [Material 名](https://jd.papermc.io/paper/1.21/org/bukkit/Material.html) のリスト。既定は金ブロックのみ。不正な名前は起動時に警告されスキップされます。
- `inspectMaxEndpoints` — 1 回の探索で列挙する終端数の上限（既定 16）。
- 探索の総ステップ数は既存の `limit` 設定が上限になります。

:::note
クリックしたレール自身の直下は判定されません。停止ブロックの上に立って、その両側をそれぞれ探索できます。
:::
